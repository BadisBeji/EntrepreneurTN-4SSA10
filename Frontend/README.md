# Frontend – Angular

Application web Angular (SPA) qui appelle uniquement l'API Gateway (`http://localhost:8080`).

Écrans prévus (version 1) : connexion / inscription, création de projet, feuille de route et progression, démarches légales et suivi, comptabilité (revenus, dépenses, bilan), aides et financements.

État : conception validée ; code à ajouter (`ng new`).
