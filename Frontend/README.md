# Frontend – Angular

Application web Angular (SPA) qui appelle uniquement l'API Gateway (`http://localhost:8080`).

Écrans prévus : connexion / inscription, création de projet, feuille de route et progression, démarches légales et suivi, facturation, comptabilité (revenus, dépenses, bilan) et capital.

État : conception validée ; code à ajouter (`ng new`).
